# Interview Explanation

## 60-second explanation
I created a Zomato restaurant analytics dashboard using Power BI. The source data contains restaurant, location, cuisine, pricing, votes, rating, table-booking and online-delivery attributes. I prepared the dataset, built the Power BI model and created KPI cards and interactive visuals. Users can filter the dashboard by year and country and analyze restaurant concentration by city, cuisine popularity, ratings, table booking and online delivery.

## Problem Statement
Restaurant datasets contain many dimensions that are difficult to analyze from raw tables. The objective is to convert raw data into an interactive management-style dashboard.

## Business Questions
- How many restaurants are represented?
- Which cities have the highest restaurant counts?
- Which cuisines are most represented?
- What is the average rating?
- How many votes are recorded?
- How common are table bookings?
- How common is online delivery?
- How do results change when filtering by year or country?

## Skills Demonstrated
Power BI, Excel, data preparation, dashboard design, KPI creation, interactive filtering, analytical storytelling and documentation.
