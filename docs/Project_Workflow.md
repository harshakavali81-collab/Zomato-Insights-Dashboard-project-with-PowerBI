# Project Workflow

Excel source → Data preparation → Power BI data model → Measures/KPIs → Dashboard visuals → Year/Country filters → Validation → Documentation → GitHub.

## Detailed steps
1. Load the Zomato Excel source.
2. Inspect columns, data types and missing values.
3. Prepare location, cuisine, booking, delivery, price, vote and rating fields.
4. Build the Power BI analytical model.
5. Create KPI calculations and visual-level metrics.
6. Build KPI cards, bar charts, combo chart and donut charts.
7. Add year and country filtering.
8. Validate headline values and interactions.
9. Package PBIX, Excel, preview and documentation.
10. Publish the project repository.

## Dashboard flow
Source Data → Preparation → Model → Measures → Visuals → Filters → Insights.
